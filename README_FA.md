# برنامه چراغ‌قوه اندروید

این پروژه یک برنامه ساده اندروید است که با یک دکمه فلاش گوشی را روشن و خاموش می‌کند.

## ساخت APK با GitHub، فقط با گوشی

1. فایل ZIP را از حالت فشرده خارج کنید.
2. وارد https://github.com شوید و یک مخزن جدید بسازید؛ نام پیشنهادی `FlashlightApp` است.
3. فایل‌ها و پوشه‌های داخل این پروژه را در مخزن بارگذاری کنید. پوشه مخفی `.github` هم باید بارگذاری شود.
4. پس از ثبت فایل‌ها، زبانه **Actions** مخزن را باز کنید.
5. اجرای **Build Android APK** را انتخاب کنید و روی **Run workflow** بزنید؛ یا پس از بارگذاری روی شاخه `main`، ساخت به‌صورت خودکار آغاز می‌شود.
6. پس از موفقیت، اجرای workflow را باز کنید و از بخش **Artifacts** فایل `flashlight-debug-apk` را دانلود کنید.
7. ZIP مربوط به Artifact را روی گوشی باز کنید و فایل `app-debug.apk` را نصب کنید. ممکن است اندروید برای نصب از این منبع، اجازه جداگانه بخواهد.

## نکات
- برنامه برای کنترل فلاش گوشی اجازه Camera را درخواست می‌کند؛ از دوربین برای عکس‌گرفتن استفاده نمی‌کند.
- این APK نسخه Debug است و برای آزمایش شخصی مناسب است؛ برای انتشار عمومی باید نسخه Release امضاشده ساخته شود.
- در برخی گوشی‌ها اگر برنامه دیگری دوربین یا فلاش را در اختیار داشته باشد، روشن‌کردن فلاش ممکن است ناموفق شود.
